04 / GOOD TO KNOW

A few things
to know.

Does NuttyMod apply changes by itself?+

No. Android restricts normal apps from running ADB shell commands. NuttyMod copies a script for you to run from a computer connected to the headset.

Will every tweak work on my headset?+

Headset software varies. Refresh rate settings may be unsupported or ignored. The other settings may also behave differently across devices.

Can I undo a setting?+

You can change the relevant Android setting back with ADB. For refresh rate, use values supported by your headset; for animations, set the scales to 1.0; for haptics, set the value to 1.
